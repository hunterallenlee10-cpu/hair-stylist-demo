# Fonts

`Fraunces-SoftWonk-600-900*.woff2` are Fraunces (SIL Open Font License 1.1, by Undercase Type,
from Google Fonts), latin subset, instanced with `scripts/trim-fonts.py`: weights 600 to 900
stay variable, SOFT is pinned at 100 and WONK at 1, which is how the site always sets it.
`DMSans-400-700.woff2` is DM Sans (SIL Open Font License 1.1, from Google Fonts), latin subset,
instanced the same way: weights 400 to 700 stay variable and optical size is pinned at 14.
