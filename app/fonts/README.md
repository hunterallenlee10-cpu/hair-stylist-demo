# Fonts

`Fraunces-SoftWonk-600-900*.woff2` are Fraunces (SIL Open Font License 1.1, by Undercase Type,
from Google Fonts), latin subset, instanced with `scripts/trim-fraunces.py`: weights 600 to 900
stay variable, SOFT is pinned at 100 and WONK at 1, which is how the site always sets it.
DM Sans still comes from `next/font/google`.
